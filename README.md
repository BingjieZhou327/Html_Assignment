# React Job Portal

A modern job portal application built with React, Material UI, and Axios. This application allows job seekers to explore job listings and company profiles with a clean and intuitive interface.

## Features

- **User Authentication**: Login system with session management using Axios
- **Job Listings**: Browse available job positions with detailed information
- **Company Showcase**: View company profiles with image galleries
- **Responsive Design**: Built with Material UI for a modern, responsive interface
- **Protected Routes**: Secure pages that require authentication
- **Session Management**: Persistent login state with logout functionality
